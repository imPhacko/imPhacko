## Research (private, available on request)

**HEP-LLM** — fine-tuned large language models (LoRA/QLoRA on Qwen2.5, Mistral) for high-energy-physics Q&A, with an automated ArXiv data-collection and instruction-tuning pipeline, and an interactive interface for comparing base vs. fine-tuned model responses.

**ParticleNet for lepton identification (CMS, CERN)** — the year-2 continuation of [ttH-higgs-pt-regression](https://github.com/imPhacko/ttH-higgs-pt-regression) above. Applied ParticleNet, a graph neural network operating on particle-level features, to improve identification of non-prompt leptons in the CMS experiment's ttH multilepton analysis, as part of my master's research within the CMS collaboration. Presented findings to the CMS ttH multilepton working group.

Happy to walk through either in more depth — some details are under collaboration/embargo restrictions, so specifics are shared on request rather than published here.
